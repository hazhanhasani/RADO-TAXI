# RADO MVP — Baneh

## Passenger
- Mobile OTP login
- Current-location pickup
- Destination search / map pin
- Favorite places
- Fare estimate
- Request ride
- Driver card + vehicle info
- Live driver position
- Call driver
- Cancel ride with reason
- Trip history
- Cash / online-payment-ready model
- Rating and support ticket

## Driver
- OTP login
- Driver onboarding status
- Online / offline
- Background location while online
- Incoming trip offer with countdown
- Accept / reject
- Navigation handoff
- Arrived / start / finish
- Daily earnings
- Wallet / commission ledger
- Trip history
- Support

## Admin
- Dashboard with live trips and online drivers
- Driver approval/suspension
- Passenger management
- Trip search and intervention
- Configurable city boundary
- Base fare, per-km, per-minute, waiting fee and surge rules
- Commission rules
- Coupons
- Wallet adjustments with audit log
- Complaints/support
- Reports
