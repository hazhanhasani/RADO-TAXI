# RADO Taxi 🚕

RADO is a city-scale ride-hailing platform designed for Baneh, Kurdistan Province, Iran.

## Products
- RADO Passenger — passenger mobile app
- RADO Driver — driver mobile app
- RADO Admin — operations/admin panel
- RADO API — auth, pricing, dispatch, trips, finance and realtime

## MVP
OTP login, pickup/destination, fare estimate, driver online/offline, nearby dispatch, atomic trip acceptance, live trip status/location, trip lifecycle, cash/online-payment-ready finance, driver commission, ratings, support and admin controls.

## Stack
- Backend: PHP 8.3 / Laravel-oriented domain architecture
- Database: PostgreSQL 16 + PostGIS
- Realtime/cache/locks: Redis
- Mobile: Flutter
- Admin: Laravel web panel
