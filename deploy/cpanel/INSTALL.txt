RADO cPanel package
Domain: https://rado-taxi.sbs

1) Extract this package into the document root of rado-taxi.sbs.
2) Ensure PHP extensions cURL and ZipArchive are enabled.
3) Add cron (adjust paths):
   */5 * * * * /usr/local/bin/php /home/CPANEL_USER/public_html/rado-system/bin/rado-update.php >/dev/null 2>&1
4) Run the updater once manually from cPanel Terminal or Cron.
5) App update endpoints:
   https://rado-taxi.sbs/api/app-updates/passenger
   https://rado-taxi.sbs/api/app-updates/driver
6) APKs are mirrored to:
   https://rado-taxi.sbs/downloads/

The updater preserves .env, storage and rado-system/state.
